# Задачник — минималистичный трекер задач

Простой и честный список дел: заголовок, срок, статус, заметка — ничего лишнего, главное, чтоб работал.

Учебный проект (кейс №2, курс «Фриланс 2026», урок FGIp07). Реализован по заказу-референсу FL.ru №3751609 («трекер задач на Swift в Xcode, без дополнительной красоты») как **веб-приложение**: Swift → ванильный JavaScript, UserDefaults → localStorage, today-extension → блок «Ближайшая задача», шаринг текста → панель «Вставить текст».

## Возможности

- **Полный CRUD**: просмотр, добавление, редактирование и удаление задач (удаление — с двухшаговым подтверждением прямо на карточке);
- задача содержит **заголовок, срок, статус** (новая / в процессе / выполнено) **и заметку**;
- **фильтр по статусу** со счётчиками: Все / Новые / В процессе / Выполненные;
- статус меняется одним движением прямо на карточке или в окне редактирования;
- **блок «Ближайшая по сроку невыполненная задача»** над списком (аналог today-extension): клик — переход к карточке с подсветкой;
- **быстрое добавление вставкой текста** (аналог шаринга): первая строка становится заголовком, остальное — заметкой;
- просроченные невыполненные задачи помечены красным бейджем «просрочена»;
- сортировка: по дате по возрастанию, выполненные — внизу;
- данные хранятся в **localStorage** браузера — без регистрации и сервера;
- при первом запуске создаются демо-задачи, чтобы приложение не выглядело пустым;
- интерфейс на русском; адаптивность: desktop → smartphone (от 360 px);
- **ванильный JS без единой библиотеки** на клиенте и подробные комментарии в коде — прямое требование исходного заказа.

## Технологии

- Node.js LTS + **Express** — сервер только раздаёт статику (никакой БД: все данные на клиенте);
- ванильные **HTML / CSS / JavaScript** — без фреймворков, сборщиков и внешних шрифтов (полностью работает офлайн).

## Локальный запуск

Нужен Node.js 18+ ([nodejs.org](https://nodejs.org)).

```bash
npm install
npm start
```

Открой http://localhost:3002 — приложение работает, данные живут в браузере.

> Совет: чтобы увидеть приложение «как в первый раз», очистите site data для localhost в DevTools → Application → Storage → Clear site data.

## Деплой на Railway

1. **Загрузи проект на GitHub:** создай новый репозиторий (например, `zadachnik-tracker`) и запушь содержимое этой папки:
   ```bash
   git remote add origin https://github.com/<твой-логин>/zadachnik-tracker.git
   git push -u origin main
   ```
2. **Задеплой на Railway:** зайди на [railway.app](https://railway.app) под аккаунтом GitHub → **New Project** → **Deploy from GitHub repo** → выбери репозиторий. Railway сам определит Node.js и выполнит `npm install` + `npm start` (конфиг — `nixpacks.toml`, порт подхватывается из переменной `PORT`).
3. **Получи публичную ссылку:** в настройках сервиса → **Networking** → **Generate Domain** — приложение откроется по адресу вида `https://<имя>.up.railway.app`.

Если сборка упала — открой лог деплоя в Railway: чаще всего достаточно обновить зависимости (`package-lock.json` должен быть в репозитории).

## Данные и приватность

- Все задачи хранятся только в localStorage твоего браузера; сервер ничего не собирает.
- Если localStorage недоступен (приватный режим), приложение работает в памяти до перезагрузки страницы.
